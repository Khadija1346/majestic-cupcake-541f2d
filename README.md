# GARRI: Rise of the Town

A mobile-first 2D browser game set in a Nigerian-inspired town. Walk the town as a Citizen, play GARRI SURVIVAL, climb the Arena, complete quests and earn collectible eligibility. $GARRI token: `0xdDDF7AB756C35b4d0537825497e6932780710241` on Robinhood Chain (chain ID 4663).

**Tech:** TanStack Start, React 19, Vite 7, Tailwind CSS 4, HTML5 Canvas, deployed on Netlify.

**Run locally:** `pnpm install` then `netlify dev` (or `pnpm dev`).

**Roadmap:** see [PLAN.md](PLAN.md) — database persistence, accounts, server score verification, Mod Hub, referral ledger, rewards, NFT minting and more mini-games come next.
